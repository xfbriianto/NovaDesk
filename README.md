# 🚀 NovaDesk

Modern SaaS Landing Page for a fictional freelancer workspace platform.

## 📌 About
NovaDesk is a UI/UX landing page project built with React and Tailwind CSS.  
It showcases a modern productivity workspace concept for freelancers, including task management, time tracking, notes, and dashboards.

## ⚡ Features
- Clean SaaS-style landing page
- Responsive design (mobile & desktop)
- Smooth scroll navigation
- Modern dark UI with neon purple glow aesthetic
- Multiple sections: Hero, Features, Pricing, Testimonials, FAQ

## 🧱 Tech Stack
- React
- Tailwind CSS v3
- Framer Motion (optional animation)
- Vite

## 🎨 Design Style
- Dark navy background
- Purple/violet neon glow accents
- Glassmorphism effects
- Minimal, modern SaaS aesthetic
